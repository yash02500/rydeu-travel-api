🚗 Rydeu Email Requirement API

Determine if a customer needs to provide their email to check ride pricing between addresses

📍 Endpoint

POST /api/check-email-required

🧑‍💻 Testing with Postman

  1. Open Postman and create a new POST request
  2. Set URL to https://rydeu-travel-api-nrqs.vercel.app/api/check-email-required
  3. Go to Body tab > Select raw > Choose JSON
  4. Enter request body (see examples below)
  5. Click Send to get response

📝 Request Body Format

{
  "pickupAddress": "Your pickup address",
  "destinationAddress": "Your destination address",
  "city": "City name",
  "vehicleType": "Economy" // (optional, defaults to Economy)
}

🏷️ Example Addresses

City: London

  • "pickupAddress": "London"
  • "destinationAddress": "Heathrow Airport"
  • "destinationAddress": "Gatwick Airport"
  • "destinationAddress": "Stansted Airport"

City: Paris

  • "pickupAddress": "Paris"
  • "destinationAddress": "Charles de Gaulle Airport"
  • "destinationAddress": "Orly Airport"

City: Berlin

  • "pickupAddress": "Berlin"
  • "destinationAddress": "Tegel Airport"
  • "destinationAddress": "Schönefeld Airport"

💡 Sample Requests

Example 1: London to Heathrow Airport

{
  "pickupAddress": "London",
  "destinationAddress": "Heathrow Airport",
  "city": "London",
  "vehicleType": "Economy"
}

Example 2: Paris to Orly Airport

{
  "pickupAddress": "Paris",
  "destinationAddress": "Orly Airport",
  "city": "Paris"
}

⚠️ Error Handling

1. Missing Required Fields

{"error": "Missing required fields: pickupAddress, destinationAddress, city"}

2. Distance Too Far

{"error": "Too far to offer ride"}

3. Invalid City or Vehicle Type

{"error": "Invalid city or vehicle type"}

📧 Email Requirement Logic

Email is required if any of these conditions are met:

  • Distance > 30 km
  • Price < €50
  • City is not London or Paris

Email is not required if all these conditions are met:

  • Distance ≤ 30 km
  • Price ≥ €50
  • City is London or Paris

🧮 Price Calculation

Price depends on:

  • City
  • Vehicle type
  • Distance
  • Airport surcharge (if applicable)

Includes base fare + per-km rate + airport fee if destination contains "airport"

🛠️ Edge Cases

  • Unlisted addresses: Random distance between 5-50 km
  • Invalid city/vehicle type: Returns error
  • Distance > 1000 km: Returns "Too far" error
